# Deployment Guide

## Laravel Cloud Deployment

This guide covers deploying StartupGraph to Laravel Cloud.

### Prerequisites

1. Laravel Cloud account
2. GitHub repository access
3. Domain name (optional: startupgraph.dev)

### Environment Variables

Copy `.env.example` to your Laravel Cloud environment and configure the following required variables:

#### Essential Configuration
```bash
APP_NAME=StartupGraph
APP_ENV=production
APP_KEY= # Auto-generated by Laravel Cloud
APP_DEBUG=false
APP_URL=https://your-domain.com  # Your actual domain

DB_CONNECTION=mysql  # Laravel Cloud provides MySQL
DB_DATABASE=startupgraph  # Your database name
# Other DB_* variables will be auto-configured by Laravel Cloud
```

#### Admin Credentials
**CRITICAL**: Change the admin credentials immediately:
```bash
ADMIN_USERNAME=your_secure_username
ADMIN_PASSWORD=your_secure_password
```

#### Mail Configuration (for notifications)
```bash
MAIL_MAILER=smtp
MAIL_FROM_ADDRESS=hello@your-domain.com
MAIL_FROM_NAME=StartupGraph
# Configure SMTP credentials for your mail service
```

#### Optional API Keys
```bash
GITHUB_TOKEN=  # For OSS project discovery
CRUNCHBASE_API_KEY=  # For funding data
PRODUCT_HUNT_TOKEN=  # For indie project discovery
```

### Database Setup

The application will automatically run migrations during deployment. For initial data:

```bash
# After deployment, seed the database
php artisan db:seed
```

### Build Process

Laravel Cloud will automatically:
1. Run `composer install --optimize-autoloader --no-dev`
2. Run `npm install && npm run build`
3. Generate optimized autoload files
4. Cache configuration and routes

### Deployment Script

Add this to your Laravel Cloud deployment script:

```bash
# Standard Laravel Cloud deployment
composer install --optimize-autoloader --no-dev
npm ci --production
npm run build

# Clear and cache config
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Run database migrations
php artisan migrate --force

# Clear application cache
php artisan cache:clear

# Generate sitemap
php artisan sitemap:generate

# Restart queue workers (if using)
php artisan queue:restart
```

### Post-Deployment Tasks

1. **Verify admin access**: Visit `/admin` and log in with your credentials
2. **Generate sitemap**: `php artisan sitemap:generate`
3. **Set up monitoring**: Configure uptime monitoring for your domain
4. **SSL Certificate**: Ensure HTTPS is properly configured

### Maintenance Tasks

Set up these scheduled tasks in Laravel Cloud (or via cron):

```bash
# Monthly: Update company headcounts
0 0 1 * * php artisan headcount:fetch-linkedin --limit=107

# Weekly: Clean up old logs
0 0 * * 0 php artisan log:clear --days=30

# Daily: Generate fresh sitemap
0 2 * * * php artisan sitemap:generate
```

### Security Considerations

1. **Admin Credentials**: Use strong, unique credentials
2. **API Keys**: Store sensitive keys securely, use environment-specific keys
3. **Database**: Regular backups via Laravel Cloud
4. **HTTPS**: Force HTTPS in production (handled by Laravel Cloud)

### Troubleshooting

#### Common Issues

1. **Migration errors**: Ensure database is properly configured
2. **Asset loading**: Check `APP_URL` matches your domain
3. **Admin access**: Verify `ADMIN_USERNAME` and `ADMIN_PASSWORD` are set
4. **File permissions**: Laravel Cloud handles this automatically

#### Useful Commands

```bash
# Check application status
php artisan about

# Clear all caches
php artisan optimize:clear

# Check database connection
php artisan tinker --execute="DB::connection()->getPdo();"

# Verify environment
php artisan config:show app.env
```

### Rollback Plan

If deployment fails:
1. Laravel Cloud provides one-click rollbacks
2. Database migrations can be rolled back with `php artisan migrate:rollback`
3. Keep previous `.env` configuration backed up

### Monitoring

Monitor these endpoints post-deployment:
- `/` - Homepage should load
- `/api/stats` - API should return database statistics
- `/admin` - Admin interface should be accessible
- `/sitemap.xml` - Sitemap should generate

### Performance Optimization

Laravel Cloud automatically provides:
- OpCache for PHP
- Redis for caching (if configured)
- CDN for static assets
- Load balancing (for higher tiers)

### Scaling

StartupGraph is designed to scale horizontally:
- Database queries are optimized with proper indexing
- File storage can move to S3 via `AWS_*` variables
- Queue processing can be distributed
- API endpoints support pagination
